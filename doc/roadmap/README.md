## 使用原则

- 历史路线文档只用于回溯，不用于证明当前功能已经生产可用。
- 当前功能是否完成，以代码、测试结果、支持文档和验证记录为准。
- 新功能优先使用 Spec Kit SDD、TDD、verification-loop 和 supporting 文档回填。
- 不再在 README 中继续扩写日程式路线图。
