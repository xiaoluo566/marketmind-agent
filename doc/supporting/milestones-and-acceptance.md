# 里程碑与验收标准

## Week 1 - 后端基础与采集链路

### 交付物

- FastAPI 项目骨架
- PostgreSQL 数据模型草案
- Celery + Redis 任务链路
- Playwright 最小爬虫
- 采集结果入库

### 验收标准

- API 能返回 `task_id`
- Worker 能消费任务
- 一个目标页面能被采集
- 采集结果能查回

## Week 2 - Agent 状态机

### 交付物

- 工具 Schema
- ReAct 循环
- Thought / Action / Observation 落库
- Pydantic 输出校验
- 重试和自修复雏形

### 验收标准

- Agent 每一步可追踪
- 工具调用前后都有状态记录
- 输出错误不会静默失败

## Week 3 - RAG 与报告

### 交付物

- 评论清洗
- 评论切片
- pgvector 检索
- 差评搜索工具
- 结构化报告

### 验收标准

- 能按语义召回差评
- 报告结论有证据来源
- 能解释产品风险维度

## Week 4 - 产品化与工程化

### 交付物

- 前端控制台
- 实时进度
- 日志与指标
- 自动化测试
- Docker Compose
- 演示和简历材料

### 验收标准

- 可以端到端演示
- 可以一键启动基础服务
- 可以回退版本
- 可以说清楚性能和失败率
