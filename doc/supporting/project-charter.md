# 项目章程

## 项目名称

MarketMind Agent：电商竞品调研与差评洞察系统。

## 项目目标

把“输入一个品类或竞品链接 -> 自动采集信息 -> 结构化分析 -> 生成可读报告”做成一个完整闭环，并且具备工程化、可追踪、可回退、可扩展的特征。

## 核心价值

- 让用户不用手动翻几十个页面和评论
- 让 Agent 能在长任务中保留状态，而不是只靠内存
- 让每一步推理、每一次工具调用、每一次失败都可追踪

## 非目标

- 不追求全网爬虫覆盖
- 不追求一开始就多服务微服务化
- 不追求“无限自治”的复杂 Agent
- 不追求重前端或高视觉表现

## 交付标准

- 能提交任务
- 能异步执行
- 能显示进度
- 能生成报告
- 能重试和回退
- 能统计耗时、错误率和成本

## 成功判定

- 单次任务链路闭环可跑通
- 关键状态落库
- 失败原因可复现
- 项目结构适合继续迭代 3 个月以上
